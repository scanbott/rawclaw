# Brand Voice

Load this before writing any content, copy, or client-facing material.

## Where to Find Your Brand Voice

Your brand voice is defined in `knowledge/client/brand-voice.md`. Read it before writing anything:

```bash
cat [RAWCLAW]/knowledge/client/brand-voice.md
```

## What It Contains

- Tone and personality
- Words to use
- Words to never use
- Writing style rules
- Platform-specific notes

## How to Apply It

1. Read `knowledge/client/brand-voice.md`
2. Write the content
3. Review: does this sound like the brand voice file describes?
4. If not, rewrite until it does

The brand voice file wins over your defaults. Always.

## Keeping It Current

When the owner gives feedback on tone or language, update `knowledge/client/brand-voice.md` so all agents benefit from that correction going forward.
