# Raw Growth — SEO Strategy

## Document Purpose
Organic growth plan for rawgrowth.ai targeting business owners searching for AI solutions. Long-term channel that compounds — every blog post is an asset that generates leads indefinitely.

---

## 1. SEO Positioning

**Domain**: rawgrowth.ai
**Target authority topic**: AI departments for online businesses
**Content angle**: Practical, specific, experience-based (not generic AI hype)
**Voice**: Chris's voice — direct, confident, young but credible, zero fluff

### Core Thesis
Raw Growth should own the search intent around "AI department" and "AI for [business type]". This is a new category — there's low competition for these terms now, but they'll explode in the next 12-18 months. Plant the flag early.

## 4. On-Page Optimization Checklist

For every blog post:
- [ ] Target keyword in title (H1)
- [ ] Target keyword in first 100 words
- [ ] Target keyword in at least one H2
- [ ] Target keyword in meta title (60 chars max)
- [ ] Target keyword in meta description (155 chars max, with CTA)
- [ ] URL slug contains target keyword (e.g., /blog/ai-department-for-business)
- [ ] Internal links to 2-3 other blog posts or pages
- [ ] External links to 1-2 authoritative sources
- [ ] Images with descriptive alt text containing keywords
- [ ] CTA in intro, mid-article, and conclusion
- [ ] Schema markup: Article, FAQ (if applicable), Organization
- [ ] Open Graph tags for social sharing
- [ ] Reading time estimate displayed
- [ ] Author bio with Chris's photo and credentials

## 5. Technical SEO Requirements

### Site Essentials
- [ ] SSL certificate (HTTPS)
- [ ] Mobile responsive design
- [ ] Page speed < 3 seconds (Core Web Vitals passing)
- [ ] XML sitemap submitted to Google Search Console
- [ ] Robots.txt configured correctly
- [ ] Clean URL structure (/blog/keyword-slug)
- [ ] 404 error page with navigation
- [ ] Canonical tags on all pages
- [ ] Structured data (Organization, Article, FAQ)

### Indexing
- [ ] Google Search Console verified
- [ ] Bing Webmaster Tools verified
- [ ] Manual index request for each new blog post
- [ ] Monitor crawl errors weekly

### Performance
- [ ] Image compression (WebP format)
- [ ] Lazy loading for images below the fold
- [ ] Minimal JavaScript (no bloat)
- [ ] CDN for static assets (Vercel handles this natively)

- UTM parameters on all CTAs (utm_source=blog, utm_medium=organic, utm_content=[post-slug])
