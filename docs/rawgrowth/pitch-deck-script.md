**For live presentations**:
- Total talk time: 18-22 minutes

- Slide 11 (case study) hits hardest after the dashboard demo -- let them see it working before showing results

- Record as Loom with face cam in bottom-left

- Skip slides 1 and 2 if rapport is already built
- Spend the most time on slides 6, 8, and 11 (content engine, dashboard, case study)
