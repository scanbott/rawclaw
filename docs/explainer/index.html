Understanding our tools

The Two Systems

Personal

RawClaw

Your personal AI department on YOUR computer

What It Is

Claude Code runs locally on your Mac, accessed via Telegram. It has full access to your files, your projects, and your machine.

How It Works

You message a Telegram bot → RawClaw runs the actual Claude Code CLI on your machine → sends the result back to your phone.

Key Features
  • Full file system access
  • Persistent memory across sessions
  • Voice input and output
  • Scheduled tasks and automations
  • Multi-agent teams
  • Web dashboard
Best For

Personal AI assistant, running code, managing files, automating YOUR workflows.

Access

Each person gets their own install on their own machine.

Think of it as “Your own AI employee that lives on your computer and you text it from your phone.”
Shared

Claude Gateway

The team’s shared AI brain in Discord

What It Is

A shared AI bot in the team Discord server. Anyone in the server can talk to it and everyone can see the conversations.

How It Works

You message in Discord → Gateway routes to the Claude API → response posted in Discord for the whole team to see.

Key Features
  • Multi-channel (Discord + Telegram)
  • Shared team context
  • Team-visible conversations
  • Sub-agent routing
Best For

Team collaboration, shared knowledge, quick questions everyone can see.

Access

One shared bot — everyone uses the same Discord server.

Think of it as “The team’s shared AI brain in Discord that everyone can talk to.”

When to Use Which

I want to… Use
Run code on my machine RawClaw
Ask a quick question the team can see Gateway
Automate my personal workflow RawClaw
Get a team-wide briefing Gateway
Access my files and projects RawClaw
Brainstorm with the team Gateway

Questions? Ask in #general on Discord.
