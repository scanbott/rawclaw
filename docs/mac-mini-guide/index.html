5 Critical Weaknesses in Your Current Setup

The most powerful Claude Code setup in existence -- chained to one desk. Here's what breaks and what the Mac Mini fixes.

Current Problem
1 Chained to Your Desk
Every skill, every automation, every build requires you at this PC. Walking to the kitchen? Can't use it. At a coffee shop? Can't use any of your 325 skills.
With Mac Mini
Mobile Freedom
Fix: Text your Telegram bot: "Run /deep-research on competitor X" -- it runs the full 10-agent research pipeline on the Mac Mini while you're at dinner. Result comes back to your phone.
Current Problem
2 Nothing Runs While You Sleep
Your /overnight skill requires the terminal open. If Windows updates, your PC restarts, or you close the laptop -- everything stops.
With Mac Mini
24/7 Uptime
Fix: Mac Mini runs 24/7 at 5W idle (~EUR 1/month electricity). Queue overnight builds before bed. Wake up to results in Telegram.
Current Problem
3 Heavy Tasks Block Everything
Running /deep-research-harness with 50 agents takes 30+ minutes. During that time, you can't use the terminal for anything else.
With Mac Mini
Parallel Streams
Fix: Send the heavy task to Mini 2 (the builder). Keep working on Mini 1 or your PC. Three parallel work streams.
Current Problem
4 Single Point of Failure
Hard drive dies? Everything gone. Yes, Git has the code, but your local state, memory, active sessions, .env, everything context -- gone.
With Mac Mini
Redundant Infrastructure
Fix: Three machines (PC + 2 Minis) with shared Supabase. Any machine can access company data. Skills sync via Git.
Current Problem
5 Your Phone AI Is Dumb
The Claude mobile app has no skills, no file access, no MCP tools, no memory across sessions. It's a generic chatbot.
With Mac Mini
Full CLI on Your Phone
Fix: RawClaw on your phone gives you the FULL Claude Code CLI. Every skill you've built works via text or voice message. It's the difference between a calculator and a computer.

Multi-Machine Sync Architecture

Three machines, one brain. Supabase for shared data, Git for skills, Tailscale for private networking.

Tailscale
Private mesh network. SSH from any device to any machine.
Claude OAuth
Same Anthropic account. One Max subscription works across all machines.

What Does NOT Sync Automatically

  • Local session state (each machine has its own conversation history)
  • Local SQLite databases (use Supabase for shared data)
  • .env files (each machine has its own keys)

Installation

Setup Steps

30 minutes from unboxing to "I'm live" on Telegram.

Mini 1: jarvis-mobile

Unbox & Connect

Connect to power + ethernet cable. That's it for hardware.

macOS Setup

5-minute wizard. Create account "jarvis", enable SSH in System Preferences.

Install Tailscale

curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up --ssh

Install RawClaw

curl -fsSL https://tinyurl.com/276p6ao5 | bash

Clone Skills

cd ~/rawclaw && git clone [repo] ~/.claude-skills && ln -s ~/.claude-skills/.claude/commands ~/.claude/commands

Setup Wizard

Paste your Telegram bot token and chat ID. Configure environment.

Start

npm run dev -- or install as launchd service for auto-start on boot.

Mini 2: jarvis-builder

Same 7 steps but with a different Telegram bot (@jarvis_builder_bot). Add to CLAUDE.md: "You are the builder agent. Focus on long-running tasks, overnight builds, deep research. Do not handle casual conversation."
